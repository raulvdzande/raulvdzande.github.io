Introductie

Over mij

Ik ben een gemotiveerde software developer van 21 jaar met een sterke focus op backend development, API-ontwerp en moderne webontwikkeling. In de afgelopen jaren heb ik diverse studie-, stage- en hobbyprojecten uitgewerkt in .NET, Laravel, JavaScript, Kotlin en Python.

Momenteel volg ik een deeltijd HBO-opleiding Informatica, waardoor ik praktijkervaring combineer met actuele theoretische kennis. Ik werk graag gestructureerd, ben gewend aan versiebeheer en code reviews, en vind het belangrijk om clean code, beveiliging en performance serieus te nemen.

Ik zoek een rol voor 32 uur per week waarin ik kan doorgroeien als backend / full-stack developer, aan professionele codebases kan meewerken en tegelijk mijn HBO-opleiding kan afronden.
