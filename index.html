Introductie

Over mij

Ik ben een gemotiveerde developer van 21 jaar met een sterke focus op backend development, API-ontwerp en moderne webontwikkeling. Naast mijn software-profiel bouw ik ook kennis op als data engineer — met oog voor data pipelines, SQL en Python-automatisering.

Ik heb 2 stages van elk 6 maanden gelopen (totaal 1 jaar stage-ervaring), waardoor ik weet hoe het is om professioneel samen te werken, met deadlines te werken en code reviews te doorlopen. Momenteel volg ik een deeltijd HBO-opleiding Informatica.

Ik zoek een rol voor 32 uur per week waarin ik kan doorgroeien — als backend developer, of in een hybride rol met data engineering — en tegelijk mijn HBO-opleiding kan afronden.
