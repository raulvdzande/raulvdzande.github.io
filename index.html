Over mij

Ik ben een gemotiveerde software developer van 21 jaar met een sterke focus op backend development, API-ontwerp en moderne webontwikkeling. Mijn technische kennis heb ik opgebouwd via studie, twee stages en eigen projecten — ik heb nog geen betaalde werkervaring in loondienst.

Ik heb 2 stages van elk 6 maanden gelopen (totaal 1 jaar stage-ervaring), waardoor ik weet hoe het is om professioneel samen te werken, met deadlines te werken en code reviews te doorlopen. Momenteel volg ik een deeltijd HBO-opleiding Informatica.

Ik zoek een rol voor 32 uur per week waarin ik kan doorgroeien als backend / full-stack developer, aan professionele codebases kan meewerken en tegelijk mijn HBO-opleiding kan afronden.
